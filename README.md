# **ECKANKAR New Mexico Venue Finder**

A lightweight, browser‑based tool for volunteers to quickly locate suitable meeting venues across New Mexico. The app filters by city, venue type, size, cost, tech availability, accessibility, and setup requirements, then generates a clean, Word‑ready table for planning and outreach.

**Data last updated: July 2026**  
Venue costs and availability may change; verify details before scheduling.

---

## **Features**
- Client‑side filtering (no backend required)  
- Clear, structured output suitable for Word documents  
- Pagination for larger result sets  
- Simplified cost categories: **Free**, **Under $200**, **Over $200**  
- Semi‑annual data updates (January / July)

---

## **File Structure**
```
index.html      — UI and filter controls  
styles.css      — Layout and visual styling  
app.js          — Filtering logic and table generation  
venues.json     — Venue dataset (July 2026 update)
```

---

## **Usage**
1. Select a city and venue type.  
2. Apply optional filters (size, cost, tech, access, setup).  
3. Click **Generate Word Table**.  
4. Copy the results into your planning document or email.

---

## **Update Cycle**
This dataset is maintained twice per year.  
Next scheduled update: **January 2027**

---

## **Purpose**
This tool supports ECKANKAR New Mexico volunteers by providing a fast, reliable way to identify meeting locations statewide. It is designed for clarity, simplicity, and ease of use during outreach and event planning.
